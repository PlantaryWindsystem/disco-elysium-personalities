# Disco Elysium · 脑内对话与思维阁

**基于游戏《极乐迪斯科》的非官方二次创作 Skill。**

让原作的 24 项技能在日常对话里继续开口：逻辑思维可能突然接通一条线索，内陆帝国可能把一件小事看成预兆，能工巧匠可能只顾着那颗拧不紧的螺丝。它们可以插话、误读、争执，也可以在一次失败的检定里卡住。

本项目沿用并改编原作的技能、思维阁与检定体验。我们的工作集中在它们如何进入持续对话、怎样保存变化，以及怎样让每个声音保持各自的思维方式。原作归属与二创边界见 [NOTICE](NOTICE.md)。

## 最想保留下来的体验

### 思维阁：让一次理解留下后续影响

从原作的 Thought Cabinet 出发，对话中反复出现的矛盾、意象或新的决定，可以形成一项思维。你选择立即研究，或先放入思维阁。新的相关经历与理解会推进研究，完成后揭示解答，并产生实际检定加成或减值。

这里有两类思维：**Elysium** 保存原作思维，**Earth** 根据用户提供的现实材料进行二创。两者明确标注，不把生成内容冒充官方文本。人物卡、研究进度与已内在化效果保存到本地，后续对话可以继续读取。

思维何时成熟、何种经历构成推进，仍由模型结合语境判断。计数只负责提醒复核，不会每隔固定轮数强行制造一项思维。

### 24 个声音，各有局限

沿用原作的四属性与 24 项技能，用参考语料校准它们的注意方向、句法节奏和失败方式。一个声音可以只说半句话，另一个可以展开很长的联想。失败也可以有内容：空白、过度怀疑、误读和冲动都有各自的位置。

### 场景决定谁开口

出场同时考虑话题与材料。身体负荷、气味、动作、工具结构、天气和城市空间，都可能唤起不同技能。人数随内容变化，不固定凑齐四种颜色；古老的爬虫脑、边缘系统与脊髓也保留独立的特殊声音规则。

### 检定有实际计算

日常被动检定使用 `6 + 有效技能值 + 情境修正`；主动检定使用真实 `2D6`，保留双 1 自动失败、双 6 自动成功。思维效果进入算式。难度与结果可以复核，排版修改不会成为重新掷骰的理由。

这些计算是本 Skill 对原作体验的适配。现实事实和必要的安全信息不由骰子决定。

## 使用

将仓库作为 `disco-elysium-personalities` 技能目录交给支持本地 Skill、文件读写和 Python 执行的助手加载。不同客户端的安装入口各异，核心入口是 [SKILL.md](SKILL.md)。

需要 Python 3.10 或以上，以及 PyYAML：

```sh
python -m pip install -r requirements.txt
```

- 输入 `Disco on` 开启，输入 `Disco off` 关闭。
- 首次启用先确认四属性分配、招牌技能和人物卡；每位用户独立建卡。
- 思维出现时选择“内在化”或“放入思维阁”。“内在化”选项表示开始研究，研究完成后才获得完成效果。
- 整理、修改或打包技能本身不会自动开启角色模式。

状态目录为 `$CODEX_HOME/state/disco-elysium-personalities`；未设置 CODEX_HOME 时使用 `~/.codex/state/disco-elysium-personalities`。状态随本地文件保存，跨设备使用需要用户自行同步。仓库不附带任何人的现成状态。
