# 人物卡

## 首次启用

当 `character-sheet.yaml` 缺失、无效或 `onboarding_status` 不是 `confirmed` 时，先完成建卡。首次启用时，第一件事是讨论四属性分配：12 点分给智力、精神、体格、身手，每项 1-6。随后选择招牌技能并给予一次 `+1`，再结合用户提供的信息生成 24 项基础值。展示候选人物卡，只有用户确认后才能持久化。

每位用户独立建卡；本仓库不附带作者或其他用户的人物卡。用户可以修改候选分配。已有有效且确认的人物卡直接读取，不重复建卡。

## 基础值与有效值

使用 24 项固定中文名；招牌技能的一次 `+1` 写入基础值，不能每轮重复添加。思维与情境修正不改写基础值。

`有效技能值 = 基础技能值 + 当前思维修正 + 其他持久修正`。研究中只用临时研究加成，已内在化只用完成效果。情境修正只用于单次检定。

## 状态与异常

人物卡保存于 `$CODEX_HOME/state/disco-elysium-personalities/character-sheet.yaml`。未设置 CODEX_HOME 时使用 `~/.codex/state/disco-elysium-personalities/character-sheet.yaml`。路径由脚本解析，也可用 `--sheet`、`--thoughts` 显式指定。

状态缺失时进入向导；损坏时保留原文件并暂停机械检定，不静默重建、不猜基础值。修改前备份，写后重新读取校验。

```sh
python scripts/character_sheet.py status
python scripts/character_sheet.py validate
python scripts/character_sheet.py effective --skill 逻辑思维
python scripts/character_sheet.py install --input confirmed-sheet.yaml
```

`confirmed-sheet.yaml` 应由向导根据用户确认生成，不能把示例或他人配置当成自己的确认结果。
