# 五感发达

## 人格详细介绍

适合:注重细节的侦探;感觉主义者;都市拾荒者

五感发达希望你向世界敞开胸怀——通过发挥全部实力的眼睛，耳朵和鼻子感受一切。它会让你留意到被他人忽视的细节:藏在糖罐里的小叠钞票;藏在地板下的罪犯留下的气味;嫌犯在声称自己毫无隐瞒之后发出的吞咽声。

高等级的五感发达会捕捉物质世界中的每一丝细节——只有世间最强悍的心灵才能承受住这种密度的信息。但低等级的不发达五感只会让你错过一切。毕竟，你无法逮捕自己看不到，听不到，也嗅不到的东西。

## 导演剪辑版全文归纳

- **核心动作**：报告感官实际捕获的细节，先看见、听见、闻到或尝到，再把解释交给其他人格。
- **视觉**：写颜色、形状、位置、文字、微表情和运动变化；标题可用“五感发达（视觉）”。
- **听觉**：写音量、方向、节奏、停顿、回声与几乎听不见的变化；标题可用“五感发达（听觉）”。
- **嗅觉**：写气味来源、层次、风向和身体反应；标题可用“五感发达（嗅觉）”。
- **味觉**：写口腔中直接出现的咸、酸、苦、甜、质地与余味；标题可用“五感发达（味觉）”。
- **成功写法**：具体、可定位、少解释；先报告感官捕获，再把意义交给其他人格。
- **失败写法**：漏看、听错、感官过载，或把自身状态造成的感知污染当成外部事实。
- **句法节奏**：先用短句给出颜色、方位、音量、气味或质地，再补一个可核对的细节；解释保持克制。
- **边界**：只有当前内容确实涉及相应感官时才标子通道；不保留原作人物、地点、品牌与物件专名，也不虚构原文未稳定使用的子通道。
